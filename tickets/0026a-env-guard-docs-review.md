# env-guard の README とコメントに残った PR レビューの指摘を反映する

## 内容

0026（env-guard の README 圧縮とコメント整理）の派生。0026 の PR に対して人間が crit で書いた指摘 11 件が、PR へ転載される前に UI でマージされたため未反映のまま残った。この枚でその 11 件を反映する。加えて、指摘を受けて kuda:prune-comment に足された 2 つの門（台帳・テストが固定している事実か / この行は真か）を 4 ファイルの全コメントブロックに掛け直し、新たに落ちた 14 件も同じ枚で処分する（2 つ目の表）。判定は 2 つの表のとおりで、実行者はこの表に従って編集する。表に無い判断が必要になったら止まって報告する。

前提は 0026 と同じ——README は conventions「README の機能節」の 3 要素（何のために / どう動くか / 保証）、コメントは kuda 同梱の記述規律（コードから読めることは書かない、台帳とテストが固定している事実は散文で持たない）。README とコメントの両方から同じ説明を消さないこと（README から落ちた説明の正本はコメント、逆も同じ）。
