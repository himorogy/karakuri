### `devcontainer-base` イメージと `examples/` の雛形3本

- 要精査 公開面と判定したが、対応するテストを持たず、何を約束にすべきかも定めていない

### `host/broker-*.sh`

- テスト未作成 差し替えた broker 環境コマンドが `NAME=VALUE` の形でない行を出したときに、その語がコマンドとして実行されない

### `scripts/init-project-firewall.sh`（egress-guard）

- テスト未作成 取得した GitHub の meta レンジは staging ではなく有効なセットへ直接足されるため、バンドルの選択を外して再実行したときに以前のレンジがセットから消える
- テスト未作成 生存判定を飛ばした実行でも、遮断側の検査（外部 DNS の遮断・未許可先の遮断）は飛ばされずに走る
- テスト未作成 遮断先の候補が1つも解決しなかった場合に「すべて許可済みだった」と報告しない（現在は両者を区別せず後者の文言を出す）
- テスト未作成 `allowHostPorts` を指定した実行で、ホスト名が解決しなかった場合に警告が出る（仕様は警告を出すと書いているが、実装にその分岐が無い）

### `runtime-base` イメージへ焼かれたコード

- テスト未作成 運用者向けに出力する文字列は、参照先のパスを伴っていても記号を含まない（現在の検査は他の2本の部分集合になっており、コメントが宣言しているこの禁止を実際には課していない）

### 配布される commit 前フック

- テスト未作成 イメージの `core.hooksPath` 経由で実際に起動する（現在のテストはフックを直接実行しており、本番の配線を通らない）
